CS 320 Portfolio Reflection 
How can I ensure that my code, program, or software is functional and secure?
I ensure functionality and security by writing thorough unit tests to catch bugs early, performing code reviews, using secure coding practices to avoid common vulnerabilities, and running automated tools to detect security issues.

How do I interpret user needs and incorporate them into a program?
I gather user requirements through interviews and documentation, then translate these needs into clear functional specifications. I focus on building features that directly solve user problems and continually seek feedback.

How do I approach designing software?
I start by breaking down complex problems into smaller components, selecting suitable design patterns, and creating a plan or diagram. I follow an iterative process to refine the design based on testing and feedback.
